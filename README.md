# Huddle Landing Page

A responsive solution to the Frontend Mentor Huddle Landing Page challenge.

## Overview

The page pairs a product mockup with a focused call to action and responsive social links, adapting cleanly from mobile to desktop.

## Built With

- Semantic HTML5
- Modern CSS
- CSS Grid
- Responsive design
- Accessible navigation and focus states
